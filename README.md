# AI Behavioral Research | Human-AI Interaction & Alignment

Soy Isabel Quiceno, psicóloga con experiencia en evaluación de sistemas de IA. Analizo cómo se comportan los modelos de lenguaje en la interacción con personas, qué riesgos aparecen y cómo se pueden medir y mitigar.

Este repositorio reúne mi trabajo de análisis aplicado, escrito para que equipos de producto e ingeniería puedan usarlo.

## Enfoque de trabajo

- Análisis orientado a decisiones: cada hallazgo se acompaña de una recomendación que un equipo pueda implementar y de una forma de medir si funciona.
- Rigor sobre afirmaciones: indico qué está respaldado por evidencia y qué es una hipótesis.
- Divulgación responsable: los informes de Red Teaming describen metodología y mitigaciones, sin instrucciones reproducibles para explotar fallos.
- Sin datos de clientes ni de plataformas de trabajo: todo el material se basa en análisis propio y ejemplos creados para este repositorio.
